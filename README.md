# 雙相情緒障礙臨床導航

繁體中文成人臨床決策輔助，涵蓋安全分流、躁／輕躁及重鬱發作評估、分期治療比較與長期追蹤。供醫療人員使用，不能取代精神科訪談、家屬佐證或處方評估。

**正式網站：https://yht5582-source.github.io/bipolar-disorder/**

## 主要功能

- 安全分流：自殺意念／計畫、精神病性症狀、嚴重失控、無法基本照顧及產後急性症狀。高風險時停止常規選藥，優先專科／急診。
- 診斷評估：核心情緒與能量、躁／輕躁七項相關症狀、時程、功能；重鬱九項症狀、時程與功能；區分 I／II 型診斷方向與既往已確認病史。
- 治療比較：依躁／輕躁、I／II 型鬱期與維持期，以及腎功能、肝功能、孕產、代謝、交互作用、既往反應和偏好，提供候選討論、劑量參考與監測。
- 追蹤：日期、情緒、睡眠、服藥比例、功能、安全警訊、選填 YMRS／MADRS 分數及鋰濃度；趨勢圖與回評日期。
- 教學及匯出：14 例虛構病例（原有 8＋新增 6）、可展開診療流程、TXT 摘要、JSON 備份還原、CSV 追蹤。

## 安全邏輯與限制

- 躁／輕躁須有一段明顯發作，不把不同時期的零散症狀相加。高昂／擴張及能量增加需三項相關症狀；僅易怒需四項。
- 輕躁不得有精神病性症狀、嚴重功能損害或住院必要，需明顯可觀察的改變。
- I 型需躁期，不必有重鬱期。II 型需輕躁及重鬱且從無躁期；原 II 型遇躁期條件須重評。
- 尚未確診、次發原因未排除、未滿18歲、孕產特殊情境或急性風險時，先完成安全／專科評估，暫不顯示常規用藥候選。
- eGFR 未提供、<60 或有增加鋰濃度交互作用時，不將鋰鹽列優先候選。此為保守安全規則，不等於應自行停掉既有鋰鹽；須精神科與腎臟科共同決策。
- Lurasidone 腎臟劑量依 CrCl，不直接以 eGFR 替代。強 CYP3A4 抑制／誘導劑時不列該藥候選。
- Lamotrigine 不治急性躁期；皮疹／黏膜病灶須緊急處理；停藥後重啟須重新評估漸增。
- I 型抗憂鬱藥不可單方；II 型非混合鬱期的特定選項由專科評估，本工具不自動推薦。
- Valproate 只列專科替代選項及安全說明。MHRA 生育限制為英國規範，不代表台灣法規。
- 劑量屬教育參考，須核對製劑、肝腎、交互作用、耐受及當地仿單。尚未逐項核實台灣 TFDA 適應症、可近性及健保給付，不能據此判定給付資格。
- 混合情境須先確認躁／輕躁或重鬱發作條件；≥65 歲、可能懷孕或計畫生育，以及既往有效藥未列候選時，會加上安全提醒。
- 治療頁修改腎肝功能、交互作用等欄位不會取消診斷確認；「更新」按鈕不能略過診斷確認。
- 鋰濃度 >1.0 mmol/L 提醒聯絡團隊，≥1.5 列疑似毒性。最近一筆追蹤有警訊時，回評日期改為隔日。
- 自評 −3 至 +3、服藥 <80% 及回評 7／30 日是本工具工作流程預設，非經驗證的自動分流規則。沒有觸發警訊不代表無風險。

## 隱私與保存

完全前端、無後端、無分析追蹤、無外部字型。評估資料不送往 GitHub 或放入 URL。

預設僅記憶體處理，重新整理會清除。可選擇瀏覽器 `localStorage`，資料未加密，同裝置使用者可能讀取，公用裝置勿啟用。不得輸入姓名、病歷號或其他個資。

TXT、CSV、JSON 下載至使用者裝置，須依院內資訊安全規範保護。清除網頁資料不會刪除已下載檔案。備份匯入會驗證欄位、日期、範圍及筆數，並關閉本機儲存。

## 原始碼與部署

無框架、無 npm 依賴，無建置步驟。

- `docs/index.html`：入口。
- `docs/style.css`：響應式介面。
- `docs/core.js`：臨床規則、病例、資料驗證。
- `docs/app.js`：互動、追蹤、匯入匯出及教學介面。
- `docs/education.js`：6 個新增病例、20 題考題與心智圖。
- `tests/clinical.test.cjs`：33 項臨床／資料情境測試。
- `tests/education.test.cjs`：13 項病例、題庫、計分與心智圖測試。

GitHub Pages：Deploy from a branch → `main` → `/docs`。

本機預覽：`python3 -m http.server 8000 --directory docs`，開啟 `http://localhost:8000`。

測試：`node tests/clinical.test.cjs`（無 node 時可用 macOS JavaScriptCore `jsc` 搭配簡易 require 墊片執行）。

## 臨床驗證狀態

軟體情境測試通過不等於前瞻性臨床驗證。正式院內使用前，應由精神科與藥師審閱內容、當地製劑及流程，指定更新負責人。


## 2026-11-13 教學更新

### 病例教學：14 例

原有八例保留，新增六例：首次精神病性躁期、拒食與 ECT 評估、疑快速循環與甲狀腺異常、CKD 腹瀉與疑鋰中毒、lamotrigine 中斷後重啟、生育規劃共同決策。每例均提供情境、解析、追蹤及來源；可篩選新增六例並載入診療流程。鋰毒性病例會建立一筆當日虛構追蹤，展示警訊，不可當成真實病人紀錄。

### 二十題考題

十題基礎與十題高階，包含診斷門檻、I／II 型分期治療、混合特徵、快速循環、腎臟劑量、毒性、交互作用、生育及長期監測。每題單選、需先選答案，送出後顯示正解、各選項解析與來源。統計唯一已作答題數與正確率，不重複累加；切換難度保留本次成績，可重新練習全部或匯出結果。成績只在本次瀏覽保留，不與病人備份混存，並非能力認證。

### 詳細心智圖

八大分支、26 個主題節點、104 個重點，採 HTML 原生 details／summary 與分支連線，具鍵盤操作、全部展開／收合、關鍵字篩選及列印。八分支涵蓋安全分流、診斷、鑑別、躁期、雙相鬱期、維持與心理照護、藥物安全／特殊族群及追蹤／隱私。

新增證據來源：NHS SPS 鋰鹽監測 https://sps.nhs.uk/monitorings/lithium-monitoring/ 。教學內容查核於 2026-11-13；主診療規則查核日期仍顯示 2026-11-12。
